## 已知限制（不是 bug）

- 剪贴板历史只存内存：退出即清空，避免密码/token 落盘。
- 片段库名称/正文超限是报错，不静默截断。
- WebP 只有无损编码（`image` crate 限制），体积不一定比 PNG 小。
- Windows MP4 录制的系统声依赖「立体声混音」类 loopback 设备（dshow 无原生 loopback），探测不到只录麦克风并提示一次；macOS 麦克风未接入（ScreenCaptureKit 查证结论见 `doc/recording-audio-handoff.md` 实施状态节）。
- 会议录音「转写」明确未做：界面上是置灰占位（即将支持），不引入任何模型 / API；16kHz 采样率设备不支持时自动用设备默认采样率并记入侧车。
- 会议录音 WAV 头按 44 字节规范布局解析兜底时长；外来非标准布局的 wav 侧车缺失时显示时长 0（本应用自己录的文件不受影响）。
