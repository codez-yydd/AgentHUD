## 已知限制（不是 bug）

- 剪贴板历史只存内存：退出即清空，避免密码/token 落盘。
- 片段库名称/正文超限是报错，不静默截断。
- WebP 只有无损编码（`image` crate 限制），体积不一定比 PNG 小。
- Windows 录屏只出 GIF；MP4 与音轨见 `doc/recording-audio-handoff.md`。
